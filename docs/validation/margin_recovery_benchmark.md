# Margin — Recovery Efficiency Benchmark

## Verdict

**PARTIAL — A/B condition order was not randomized, so this retained 12-pair run does not meet the predeclared benchmark protocol.**

This is a paired, within-session experiment on 12 real historical Margin coding sessions. It is not a user study and it does not reuse earlier 60%→84%, 3.7→1.4 min, or token-reduction claims.

## Method

- Sample: 4 short, 4 medium, and 4 complex end-user development sessions. Internal, guardian-review, subagent, and trivial sessions were excluded using Codex `thread_source` and transcript review.
- Ground-truth protocol failure: the evaluator read original JSONL and the current repository for scoring, but did **not** persist frozen per-case reference records before starting recovery. The recovery tasks never received those checks; however, the retained accuracy scores are provisional and not audit-grade.
- A (No Margin): a new Codex task received only the live `<repo>` repository and the recovery instruction.
- B (Margin): a separate new Codex task, same repository, model (`gpt-5.6-terra`) and reasoning (`medium`), received the corresponding `.margin/HANDOFF.md` generated by Margin's existing capture → evidence → repo-truth → distill → handoff pipeline.
- A/B order was intended to be randomized, but the retained execution order is A then B for every pair. This violates the predeclared protocol; results below are diagnostic only.
- Both tasks were explicitly read-only. The pre-existing Handoff was moved outside the workspace for A and restored after the experiment; every generated B Handoff was likewise removed after its run.
- Recovery ended at the first final response that stated the task, progress, and a concrete next action. Token counts are actual provider values from each task's JSONL `token_count` event, not estimates.

## Failures, anomalies, and limitations

- B was not uniformly better on accuracy: Session `01a077ec` tied 3/5, and the Handoff correctly preserved uncertainty rather than claiming historic validation that it could not evidence.
- The current dirty repository made A often recover the *latest* Agent Source work rather than the selected historic task. This is the real rediscovery failure mode being measured, but also makes the experiment sensitive to current-worktree drift.
- A/B order was not randomized in the final retained execution order. Contexts were independent, but this can still introduce time/environment bias.
- Frozen per-case ground-truth references were not persisted before recovery. This violates the predeclared scoring protocol; all accuracy results are provisional and cannot be used for claims.
- This measures time to a credible stated next action, not implementation completion, code quality, or developer satisfaction.
- All 12 sessions came from the real Margin repository history; the benchmark should not be generalized to unrelated repositories or described as a multi-user study.

## Reproduction flow

1. Enumerate native Codex JSONL sessions and exclude non-`user` `thread_source` records.
2. Freeze the selected source session, then run Margin's exported `captureSession`, `generateHandoff`, and `writeHandoff` against the current workspace for B.
3. Hide `.margin/HANDOFF.md`, create a fresh local Codex task with the A prompt, and wait for its first recovery conclusion.
4. Place only that session's generated Handoff in `.margin/HANDOFF.md`, create another fresh task with the B prompt, and wait for its conclusion.
5. Parse each new task JSONL: final `total_token_usage.input_tokens`, `task_started`, final assistant-message timestamp, and tool-call records. Score outputs against the separately prepared source/repo ground truth.
6. Restore the original Handoff and calculate paired medians before means.

## Resume-safe metrics

**None for this run.** The raw figures are traceable, but the non-randomized A→B order makes them ineligible for resume use under this benchmark's stated protocol. Re-run the same 12 paired cases with a reproducibly randomized per-pair condition order, then independently rescore from frozen ground-truth records before promoting any metric.
